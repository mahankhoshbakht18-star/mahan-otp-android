## آزمون‌های اجراشده

- اندروید: ۶۷ تست واحد، صفر خطا: ۲۵ تست سازگاری قبلی، ۳۲ تست نوع پیامک/تطبیق/دانلود و ۱۰ تست متادیتای نسخه.
- رله: ۲۳ تست انتقال و نوع عملیات، ۱۵ تست مدیریت انتشار و یک تست مهاجرت پایگاه داده؛ مجموع ۳۹ تست موفق.
- اتصال بات: ۱۰ تست موفق روی دیتابیس موقت و Mock شبکه؛ بدون اجرای مرورگر بات یا ارسال پیام واقعی.
- پنل: ۷ بررسی رابط با داده آزمایشیِ مشخص، شامل RTL، حالت خالی، عدم نمایش نصب فرضی، عرض موبایل، دیالوگ پایلوت، الزام گزارش آزمون و نبود خطای JavaScript. تصاویر دسکتاپ و موبایل ذخیره شدند.
- کپچا: مقایسه AST تمام ۹ تابع کپچا/فایروال در سه ماژول بات با پشتیبان پیش از این کار؛ بدون تغییر.
- Patch بات: `git apply --check` روی کپی موقتِ پشتیبان پیش از مأموریت موفق شد؛ تغییرهای قبلی کاربر در بات بازنویسی نشده‌اند.
- آزمایش انتشار با خود APK امضاشده: بارگذاری، بررسی واقعی امضا و بسته با Java/Android SDK، ساخت پیش‌نویس؛ متادیتا و دانلود عمومی هر دو 404 بودند. نصب ثبت‌شده‌ای جعل نشده است.
- بررسی سورسِ تحت Git: اعتبارنامه واقعی فایل اتصال در فایل‌های tracked پیدا نشد. فایل اتصال و Keystore در Git نیستند.
- سرور عملیاتی با بررسی فقط‌خواندنی: همچنان نسخه عمومی ۲.۱.۰ / Build 4؛ هش کد سرویس بدون تغییر.
- سازگاری روی آروان: کد جدید با Python 3.12.3 و FastAPI/Pydantic نصب‌شده در مسیر موقت خصوصی اجرا شد؛ startup، ساخت DB موقت و تولید OpenAPI موفق بود. فایل محیط و دیتابیس Production بارگذاری نشدند و سرویس اصلی ری‌استارت نشد.

## آزمون نصب و اجرا

اجرای شبیه‌ساز ایزوله API 24 و 35 در GitHub Actions تعریف شده است: نصب ۲.۱.۰، ایجاد تنظیمات/صف رمزنگاری‌شده با Android Keystore واقعی، نصب `-r` نسخه ۲.۲.۰، بررسی UUID/کلید/آدرس/کد ملی/شناسه رویداد، دریافت پیامک آزمایشی، نصب تازه، بررسی رضایت پیش‌فرض و بازکردن پشتیبانی.

نتیجه نهایی شبیه‌ساز و Lint پس از پایان اجرا در پیوست تحویل ثبت می‌شود. تعریف این workflow به‌تنهایی به معنی موفقیت نصب نیست.

اجرای نخست Lint دو خطای MissingTranslation برای نام برنامه و متن «هنوز رویدادی ثبت نشده است» یافت؛ متن‌ها از قبل فارسی بودند اما نسخه `values-fa` نداشتند. هر دو به منابع فارسی اضافه شدند. ۸۱ هشدار غیرمسدودکننده عمدتاً مربوط به نسخه جدیدتر وابستگی‌ها، متن‌های ثابت رابط قبلی و منابع بلااستفاده بود؛ ادعای صفر هشدار نشده است. ثابت EXTRA_SUBSCRIPTION_INDEX روی API قدیمی فقط یک رشته inlined است و فراخوانی SubscriptionManager.getSlotIndex با شرط API 29 محافظت شده است.

## مواردی که موفقیتشان ادعا نشده است

- گروه پایلوت انسانی و آزمون گوشی‌های واقعی/دوسیم‌کارت، Doze، خاموشی نمایشگر، راه‌اندازی مجدد، لغو مجوز و Force stop هنوز لازم است.
- خطای واقعی کمبود فضای گوشی، رد نصب توسط کاربر و قطع دانلود از رابط واقعی Package Installer نیازمند آزمون دستگاه است؛ تست‌های سیاست/جریان جایگزین این آزمون‌ها نیستند.
- ارسال اعلان دوره‌ای تحت زمان‌بندی واقعی اندروید و گزارش اجرای پس از آپدیت باید در پایلوت دیده شود؛ FCM در نسخه قدیمی وجود ندارد و اضافه‌شدن از راه دور ممکن نیست.
- Production عمداً ارتقا نیافته است. برای فعال‌شدن انواع جدید در عملیات واقعی، تغییرهای رله و بات، ابزارهای تأیید APK و کلید مستقل مدیریت باید پس از تأیید مالک مستقر شوند.
- سرور فعلی Java/aapt/apksigner ندارد؛ تا نصب و تنظیم ابزار معتبر، بارگذاری نسخه در پنل fail-closed می‌ماند.
- کلید مشترک داخل APK برای سازگاری حفظ شده و مانند هر راز داخل APK قابل استخراج است؛ مهاجرت به کلید مجزا برای هر نصب، کار بعدی مجزا است.
- رفع همه هشدارهای نصب/Play Protect یا اخذ مجوز انتشار Google Play تضمین نشده و قابل صدور از طرف برنامه‌نویس نیست.

## مشکلات هدف و اصلاح‌ها

۱. تشخیص قبلی برای قالب ثبت‌نام بود؛ تشخیص نوع‌دار و جلوگیری از مصرف متقاطع بازیابی/حذف اضافه شد.
۲. پیامک بدون متن و درخواست‌های نزدیک/مبهم برای انتخاب خودکار کافی نیستند؛ مرحله تأیید و قفل مقصد اضافه شد.
۳. دانلود و نصب امن فقط لینک نیست؛ کنترل جریان، هش، هویت بسته، گواهی و نسخه افزایشی قبل از نصاب رسمی اضافه شد.
۴. داشتن کلید بات معادل مجوز حذف یا انتشار نیست؛ کلید مستقل مدیریت، تأیید صریح مدیر و توکن محدود به درخواست اضافه شد.
۵. گزارش اعلان مساوی نصب نیست؛ آمار به گزارش واقعی نصب‌های موافق و حالت «نامعلوم» برای کاربران قدیمی محدود شد.
